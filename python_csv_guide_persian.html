آموزش کامل کار با فایل‌های CSV در پایتون

فرمت CSV یکی از پرکاربردترین روش‌ها برای ذخیره و تبادل داده‌های ساختاریافته است. در این جزوه، روش‌های خواندن و نوشتن فایل‌های CSV با ماژول داخلی csv و کتابخانه قدرتمند Pandas را به شکل تعاملی فرامی‌گیرید.

⚡ پردازشگر و شبیه‌ساز زنده CSV 
import csv

with open('data.csv', mode='r', encoding='utf-8') as file:
    reader = csv.reader(file, delimiter=',')
    for row in reader:
        print(row)

📖 نمونه کدهای پایتون

۱. خواندن فایل CSV به صورت لیست

استفاده از csv.reader برای پیمایش خط به خط داده‌ها به شکل لیست.

import csv

with open('data.csv', mode='r', encoding='utf-8') as file:
    reader = csv.reader(file)
    
    header = next(reader)  # خواندن هدر
    print("ستون‌ها:", header)
    
    for row in reader:
        print(row)  # هر سطر یک لیست است

۲. خواندن فایل با DictReader

تبدیل هر سطر به یک دیکشنری با کلیدهای برگرفته از هدر جدول.

import csv

with open('users.csv', mode='r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    
    for row in reader:
        print(f"نام: {row['Name']} | نقش: {row['Role']}")

۳. نوشتن در فایل CSV با writer

ذخیره داده‌های لیستی در فایل CSV با رعایت فرمت استاندارد.

import csv

data = [
    ['Name', 'Age', 'City'],
    ['Ali', 28, 'Tehran'],
    ['Sara', 24, 'Shiraz']
]

with open('output.csv', mode='w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file)
    writer.writerows(data)

۴. نوشتن با DictWriter

ذخیره مجموعه‌ای از دیکشنری‌ها در فایل CSV همراه با تولید هدر.

import csv

fieldnames = ['Name', 'Age', 'Role']
users = [
    {'Name': 'Ali', 'Age': 28, 'Role': 'Dev'},
    {'Name': 'Sara', 'Age': 24, 'Role': 'UI/UX'}
]

with open('users_out.csv', mode='w', newline='', encoding='utf-8') as file:
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(users)

۵. کار با CSV در Pandas (حرفه‌ای)

سریع‌ترین و قدرتمندترین روش برای تحلیل و پردازش داده‌های CSV.

import pandas as pd

# خواندن فایل
df = pd.read_csv('data.csv')

# فیلتر کردن
filtered_df = df[df['Age'] > 25]

# ذخیره در فایل جدید
filtered_df.to_csv('filtered.csv', index=False, encoding='utf-8')

۶. تغییر جداکننده (Delimiter)

خوانش فایل‌هایی که با سیمیکالن (;) یا تب (\t) تفکیک شده‌اند.

import csv

# خواندن فایل با جداکننده سیمیکالن
with open('data_semicolon.csv', mode='r', encoding='utf-8') as file:
    reader = csv.reader(file, delimiter=';')
    for row in reader:
        print(row)

📊 جدول پارامترهای مهم ماژول csv

پارامتر مقدار پیش‌فرض توضیحات
delimiter ',' کاراکتر جداکننده ستون‌ها (مانند کاما، سیمیکالن یا تب).
quotechar '"' کاراکتر قرارگیری دور مقادیری که شامل جداکننده هستند.
quoting QUOTE_MINIMAL نحوه کوتیشن‌گذاری (QUOTE_ALL، QUOTE_NONNUMERIC و ...).
escapechar None کاراکتر اسکیپ برای نادیده گرفتن کاراکترهای خاص.
lineterminator '\r\n' کاراکتر پایان سطر هنگام نوشتن فایل.
skipinitialspace False حذف فضاهای خالی پس از جداکننده.
