HTTP for Humans™

راهنمای جامع ماژول Requests در پایتون

کتابخانه Requests محبوب‌ترین و ساده‌ترین ابزار پایتون برای ارسال درخواست‌های HTTP و ارتباط با وب‌سرویس‌ها (REST APIs) است.

۱. نصب و راه‌اندازی

برای نصب کتابخانه Requests، در ترمینال یا خط فرمان سیستم خود دستور زیر را اجرا کنید:

bash 
pip install requests

۲. متدهای اصلی HTTP

چهار عملیات اصلی ارتباط با سرور (CRUD) در این ماژول مستقیماً با توابع هم‌نام فراخوانی می‌شوند:

GET

دریافت اطلاعات از سرور

POST

ایجاد یا ارسال داده جدید

PUT

بروزرسانی کامل اطلاعات

DELETE

حذف یک منبع از سرور

python 
import requests

# ارسال درخواست GET
response = requests.get("https://api.github.com/events")

# سایر متدها
requests.post("https://httpbin.org/post", data={"key": "value"})
requests.put("https://httpbin.org/put", data={"key": "value"})
requests.delete("https://httpbin.org/delete")

۳. ارسال پارامتر در URL (Query Strings)

به‌جای چسباندن دستی علامت سؤال و مقادیر به انتهای آدرس، یک دیکشنری به آرگومان params بدهید تا به‌صورت استاندارد کدگذاری (URL-Encode) شود:

python 
import requests

query_params = {
    "q": "python requests",
    "page": 2
}

response = requests.get("https://httpbin.org/get", params=query_params)

print(response.url)
# خروجی: https://httpbin.org/get?q=python+requests&page=2

۴. بررسی محتوای پاسخ (Response Object)

وقتی درخواستی ارسال می‌کنید، یک شیء Response برگردانده می‌شود که تمام اطلاعات پاسخ سرور را در خود دارد:

ویژگی / متد کاربرد نوع خروجی
response.status_code کد وضعیت HTTP (مثل 200، 404، 500) عدد صحیح (int)
response.text محتوای متنی پاسخ (مناسب برای HTML یا متن) رشته (str)
response.json() تبدیل خودکار پاسخ JSON به دیکشنری پایتون دیکشنری یا لیست
response.content محتوای باینری خام (مناسب برای دانلود عکس و فایل) بایت (bytes)
response.headers مشاهده هدرهای بازگشتی از سمت سرور دیکشنری

۵. ارسال داده و JSON در متد POST

برای ارسال داده به APIهای مدرن، استفاده از آرگومان json بهترین روش است؛ زیرا علاوه‌بر تبدیل دیکشنری به رشته JSON، هدر Content-Type: application/json را نیز خودکار تنظیم می‌کند.

python 
import requests

payload = {
    "username": "ali_dev",
    "role": "admin"
}

response = requests.post("https://httpbin.org/post", json=payload)

if response.status_code == 200:
    data = response.json()
    print(data["json"])

۶. هدرهای سفارشی و توکن احراز هویت

برای ارسال توکن‌های امنیتی (مانند Bearer Token) یا تغییر User-Agent، یک دیکشنری به آرگومان headers پاس دهید:

python 
import requests

custom_headers = {
    "User-Agent": "MyPythonApp/1.0",
    "Authorization": "Bearer YOUR_SECRET_TOKEN"
}

response = requests.get("https://httpbin.org/headers", headers=custom_headers)
print(response.json())

۷. مدیریت زمان انتظار (Timeout) و خطاها

همیشه در پروژه‌های واقعی برای درخواست‌های خود timeout تعیین کنید تا برنامه در صورت کندی سرور، بی‌نهایت متوقف نماند.

python 
import requests
from requests.exceptions import RequestException, Timeout

try:
    # حداکثر ۵ ثانیه منتظر پاسخ می‌ماند
    response = requests.get("https://httpbin.org/delay/2", timeout=5)
    
    # اگر کد وضعیت 4xx یا 5xx باشد خطا تولید می‌کند
    response.raise_for_status()
    print("درخواست با موفقیت انجام شد!")

except Timeout:
    print("خطا: مهلت زمانی اتصال به سرور به پایان رسید.")
except RequestException as e:
    print(f"خطا در برقراری ارتباط: {e}")
نکته مهم: بدون تنظیم timeout، ممکن است برنامه شما در صورت قطع ارتباط سرور برای همیشه قفل (Hang) شود.

۸. استفاده از Session (افزایش سرعت و حفظ کوکی‌ها)

وقتی چندین درخواست پیاپی به یک سرور می‌فرستید، استفاده از Session باعث می‌شود اتصال TCP باز بماند (Connection Pooling) و سرعت درخواست‌ها به شکل چشمگیری افزایش یابد:

python 
import requests

with requests.Session() as session:
    # این هدر برای تمام درخواست‌های بعدی این سشن ارسال می‌شود
    session.headers.update({"Authorization": "Bearer TOKEN_123"})
    
    res1 = session.get("https://httpbin.org/cookies/set/session_id/98765")
    res2 = session.get("https://httpbin.org/cookies")
    
    print(res2.json())  # کوکی تنظیم شده در درخواست اول حفظ شده است
