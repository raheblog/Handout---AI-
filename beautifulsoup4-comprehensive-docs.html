مرجع کامل و کاربردی Beautiful Soup 4 در پایتون

کتابخانه Beautiful Soup قدرتمندترین و محبوب‌ترین ابزار پایتون برای استخراج داده از فایل‌های HTML و XML است. این کتابخانه با ساخت یک درخت پیمایشی (Parse Tree) از تگ‌های صفحه وب، به شما امکان می‌دهد حتی از صفحات وب با کدنویسی نامرتب و شکسته، اطلاعات را با کمترین کد استخراج کنید.

۱ معرفی و نحوه عملکرد Beautiful Soup 4

برخلاف کتابخانه requests که وظیفه دانلود سورس صفحه وب را بر عهده دارد، Beautiful Soup هیچ درخواستی به اینترنت ارسال نمی‌کند؛ بلکه رشته متنی HTML یا XML دریافت‌شده را تحویل گرفته و آن را به مجموعه‌ای از اشیاء پایتونی تو در تو تبدیل می‌کند.

مقایسه مفسرها (Parsers) در Beautiful Soup

هنگام ساخت شیء BeautifulSoup، باید مشخص کنید از کدام موتور تجزیه‌کننده استفاده شود:

نام مفسر (Parser) نحوه فراخوانی سرعت مزایا و معایب
پارسر داخلی پایتون "html.parser" متوسط بدون نیاز به نصب پکیج جانبی، سرعت مناسب، حساسیت متوسط به HTML خراب.
مفسر LXML (پیشنهادی) "lxml" بسیار سریع ⚡ سریع‌ترین گزینه، نوشته شده به زبان C، نیازمند نصب پکیج lxml.
مفسر LXML XML "xml" یا "lxml-xml" بسیار سریع ⚡ تنها مفسر رسمی پشتیبانی‌کننده از فایل‌های XML، فیدهای RSS و Sitemap.
مفسر HTML5lib "html5lib" کند صفحه را دقیقاً مانند یک مرورگر واقعی تفسیر می‌کند؛ عالی برای صفحات به‌شدت نامرتب.
توصیه حرفه‌ای: در پروژه‌های اسکرپینگ، همیشه از "lxml" به عنوان پارسر پیش‌فرض استفاده کنید؛ زیرا تا چند برابر سریع‌تر از html.parser عمل می‌کند.

۳ شروع کار و شناخت اشیاء چهارگانه در BS4

درک معماری Beautiful Soup با شناخت ۴ نوع شیء کلیدی که پس از تجزیه سند تولید می‌شوند بسیار ساده می‌شود:

python — basic_objects.py
from bs4 import BeautifulSoup, Comment

html_doc = '''
<html>
    <head><title>فروشگاه کتاب پایتون</title></head>
    <body>
        <!-- این یک کامنت تستی در سورس است -->
        <h1 class="main-title" id="header">لیست کتاب‌های ویژه</h1>
        <p class="desc">بهترین منابع آموزش برنامه‌نویسی</p>
    </body>
</html>
'''

# ۱. شیء BeautifulSoup (کل سند را نمایندگی می‌کند)
soup = BeautifulSoup(html_doc, "lxml")

# ۲. شیء Tag (نماینده یک تگ HTML یا XML)
h1_tag = soup.h1
print(type(h1_tag))          # <class 'bs4.element.Tag'>

# ۳. شیء NavigableString (متن داخل تگ)
title_text = soup.h1.string
print(type(title_text))      # <class 'bs4.element.NavigableString'>

# ۴. شیء Comment (کامنت‌های داخل HTML، زیرمجموعه‌ای از NavigableString)
comment = soup.find(string=lambda text: isinstance(text, Comment))
print(comment.strip())       # این یک کامنت تستی در سورس است

۴ دسترسی به تگ‌ها، نام و ویژگی‌ها (Attributes)

هر شیء Tag دارای نام (.name) و دیکشنری ویژگی‌ها (.attrs) است. برای خواندن ویژگی‌هایی مثل href، src یا id می‌توانید مانند دیکشنری‌های پایتون با آن رفتار کنید.

python — attributes.py
from bs4 import BeautifulSoup

html = '<a href="https://python.org" class="btn btn-primary" data-id="105">سایت پایتون</a>'
soup = BeautifulSoup(html, "lxml")
link = soup.a

# نام تگ
print(link.name)                # 'a'

# دریافت همه ویژگی‌ها به صورت دیکشنری
print(link.attrs)               # {'href': 'https://python.org', 'class': ['btn', 'btn-primary'], 'data-id': '105'}

# دو روش دسترسی به یک ویژگی خاص
print(link["href"])             # اگر ویژگی وجود نداشته باشد خطای KeyError می‌دهد
print(link.get("href"))         # ایمن‌تر: در صورت نبود ویژگی، None برمی‌گرداند
print(link.get("target", "_self")) # تعیین مقدار پیش‌فرض در صورت نبود ویژگی

# ویژگی‌های چندمقداری (مثل class) به صورت لیست برگردانده می‌شوند
print(link["class"])            # ['btn', 'btn-primary']
نکته مهم امنیتی در کدنویسی: همیشه به جای tag['href'] از متد tag.get('href') استفاده کنید تا اگر یکی از تگ‌های صفحه فاقد لینک بود، اسکریپت شما با خطای KeyError متوقف نشود.

۵ توابع جستجوی اصلی: find() و find_all()

پراستفاده‌ترین متدها در Beautiful Soup این دو تابع هستند. متد find() تنها اولین نتیجه منطبق را برمی‌گرداند (یا None در صورت نیافتن)، در حالی که find_all() لیستی از تمام تگ‌های منطبق (ResultSet) را برمی‌گرداند.

امضای کامل متد find_all

find_all(name, attrs, recursive, string, limit, **kwargs)

python — find_examples.py
from bs4 import BeautifulSoup

html = '''
<div id="products">
    <article class="item featured" data-category="book">
        <h2>آموزش جامع پایتون</h2>
        <span class="price">250000</span>
    </article>
    <article class="item" data-category="course">
        <h2>دوره هوش مصنوعی</h2>
        <span class="price">890000</span>
    </article>
    <article class="item" data-category="book">
        <h2>وب اسکرپینگ پیشرفته</h2>
        <span class="price">320000</span>
    </article>
</div>
'''
soup = BeautifulSoup(html, "lxml")

# ۱. جستجو بر اساس نام تگ
all_articles = soup.find_all("article")

# ۲. جستجو بر اساس کلاس CSS (توجه به زیرخط در class_ به دلیل کلمه کلیدی بودن در پایتون)
featured = soup.find("article", class_="featured")

# ۳. جستجو با دیکشنری attrs (مناسب برای ویژگی‌های دارای خط تیره مثل data-*)
books = soup.find_all("article", attrs={"data-category": "book"})

# ۴. محدود کردن تعداد نتایج با limit
top_two = soup.find_all("article", limit=2)

# ۵. جستجو بر اساس متن دقیق داخل تگ با آرگومان string
target_h2 = soup.find("h2", string="دوره هوش مصنوعی")

# ۶. جستجو فقط در فرزندان مستقیم (غیربازگشتی)
direct_children = soup.div.find_all("article", recursive=False)
میانبر در BS4: فراخوانی مستقیم soup("article") دقیقاً معادل soup.find_all("article") است و soup.article معادل soup.find("article") می‌باشد.

۶ انتخابگرهای پیشرفته CSS با select() و select_one()

اگر با فرانت‌اند و CSS آشنایی دارید، متدهای select() (معادل querySelectorAll) و select_one() (معادل querySelector) نوشتن کوئری‌های پیچیده و تودرتو را فوق‌العاده راحت می‌کنند.

python — css_selectors.py
# ۱. انتخاب بر اساس کلاس (.) و آیدی (#)
header = soup.select_one("#products")
items = soup.select(".item.featured")  # تگ‌هایی که هر دو کلاس را همزمان دارند

# ۲. انتخاب تگ‌های تودرتو (اعقاب و فرزندان مستقیم)
all_h2_inside_div = soup.select("div#products article h2")
direct_articles = soup.select("div#products > article")  # فقط فرزند مستقیم

# ۳. انتخابگرهای ویژگی (Attribute Selectors)
secure_links = soup.select('a[href^="https://"]')      # شروع با https://
pdf_files = soup.select('a[href$=".pdf"]')             # پایان با .pdf
contains_shop = soup.select('a[href*="shop"]')         # شامل کلمه shop

# ۴. انتخابگرهای شبه کلاس (Pseudo-classes)
second_article = soup.select_one("article:nth-of-type(2)")
not_featured = soup.select("article:not(.featured)")

# ۵. انتخاب تگ‌های هم‌سطح (Siblings)
next_sibling = soup.select_one("h2 + span.price")      # تگ span بلافاصله بعد از h2

۷ فیلترهای هوشمند: Regex، لیست‌ها و توابع Lambda

گاهی در صفحات وب داینامیک، نام کلاس‌ها یا آیدی‌ها دارای اعداد تصادفی است (مثلاً product-row-849) یا می‌خواهید تگ‌هایی را بیابید که شرط‌های منطقی خاصی دارند. در این حالت، ترکیب BS4 با ماژول re و توابع lambda معجزه می‌کند:

python — regex_lambda_filters.py
import re
from bs4 import BeautifulSoup

# ۱. ارسال لیست: یافتن همزمان چندین تگ مختلف
headings = soup.find_all(["h1", "h2", "h3"])

# ۲. استفاده از عبارات باقاعده (Regex)
# یافتن تگ‌هایی که آیدی آن‌ها با item- شروع شده و به عدد ختم می‌شود
dynamic_items = soup.find_all("div", id=re.compile(r"^item-\d+$"))

# یافتن تگ‌هایی که متن آن‌ها شامل کلمه 'تخفیف' است
discount_tags = soup.find_all(string=re.compile("تخفیف"))

# ۳. استفاده از مقدار True (یعنی ویژگی وجود داشته باشد، مهم نیست مقدارش چیست)
tags_with_id = soup.find_all(id=True)

# ۴. فیلتر سفارشی با تابع Lambda
# یافتن تگ‌های article که دقیقاً ۲ ویژگی دارند و متن داخلشان بیشتر از ۲۰ کاراکتر است
custom_matches = soup.find_all(
    lambda tag: tag.name == "article" 
    and len(tag.attrs) == 2 
    and len(tag.get_text(strip=True)) > 20
)

۸ پیمایش درخت DOM (حرکت به بالا، پایین و طرفین)

زمانی که یک تگ مرجع را پیدا کردید، می‌توانید بدون جستجوی مجدد، به والدین، فرزندان یا تگ‌های همسایه (خواهر و برادر) آن دسترسی پیدا کنید:

جهت حرکت ویژگی / متد توضیح کاربردی
رو به پایین (فرزندان) .contents و .children فرزندان مستقیم یک تگ را برمی‌گرداند (شامل تگ‌ها و رشته‌های متنی/فاصله‌ها).
رو به پایین (کل زیرمجموعه) .descendants یک Generator که تمام فرزندان، نوه‌ها و زیرمجموعه‌ها را به صورت بازگشتی پیمایش می‌کند.
رو به بالا (والد) .parent و .parents دسترسی به تگ دربرگیرنده مستقیم یا حرکت پله‌پله تا رسیدن به ریشه سند.
رو به طرفین (هم‌سطح) .next_sibling / .previous_sibling حرکت به عنصر هم‌سطح بعدی یا قبلی در همان والد.
جستجوی هوشمند در اطراف .find_parent() / .find_next_sibling() برخلاف .next_sibling که ممکن است فاصله خالی ( ) را بگیرد، این متدها فقط تگ واقعی مدنظر را می‌یابند.
python — dom_navigation.py
price_tag = soup.find("span", class_="price")

# یافتن کارت محصولی که این قیمت داخل آن قرار دارد (حرکت به بالا)
product_card = price_tag.find_parent("article")

# یافتن تگ هم‌سطح قبلی (عنوان محصول که قبل از قیمت آمده است)
title_tag = price_tag.find_previous_sibling("h2")
print(title_tag.text)

۹ استخراج تمیز متن و تبدیل جداول HTML به داده

برای استخراج متن از درون تگ‌ها، متد .get_text() بسیار قدرتمندتر از .string است؛ زیرا متن تمام زیرتگ‌ها را با هم ادغام کرده و به شما اجازه می‌دهد فاصله‌های اضافی را حذف کنید.

python — text_and_tables.py
# ۱. استخراج متن تمیز با جداکننده دلخواه و حذف فاصله‌های ابتدا و انتها
clean_text = soup.get_text(separator=" | ", strip=True)

# ۲. دریافت لیست تمام متن‌های غیرخالی داخل یک بخش با stripped_strings
texts_list = list(soup.div.stripped_strings)

# ۳. الگوهای استاندارد استخراج جدول HTML (<table>) به لیست دیکشنری‌ها
table_html = '''
<table id="crypto">
    <thead><tr><th>ارز</th><th>نماد</th><th>قیمت ($)</th></tr></thead>
    <tbody>
        <tr><td>بیت‌کوین</td><td>BTC</td><td>68500</td></tr>
        <tr><td>اتریوم</td><td>ETH</td><td>3600</td></tr>
    </tbody>
</table>
'''
table_soup = BeautifulSoup(table_html, "lxml")

headers = [th.get_text(strip=True) for th in table_soup.select("thead th")]
rows_data = []

for tr in table_soup.select("tbody tr"):
    cells = [td.get_text(strip=True) for td in tr.find_all("td")]
    rows_data.append(dict(zip(headers, cells)))

۱۰ ویرایش، حذف و دستکاری درخت HTML

Beautiful Soup تنها برای خواندن اطلاعات نیست! شما می‌توانید تبلیغات مزاحم، تگ‌های <script> یا <style> را قبل از پردازش متن حذف کنید، یا تگ‌های جدید بسازید و فایل HTML ویرایش‌شده را ذخیره کنید.

python — modify_dom.py
from bs4 import BeautifulSoup

soup = BeautifulSoup('<div class="box"><script>alert(1)</script><p>متن اصلی</p></div>', "lxml")

# ۱. حذف کامل تگ‌های مزاحم (مثل اسکریپت‌ها و تبلیغات) با decompose()
for script in soup.find_all(["script", "style"]):
    script.decompose()  # تگ را از درخت حذف و از حافظه پاک می‌کند

# ۲. تفاوت extract() با decompose(): متد extract تگ را جدا کرده و برمی‌گرداند
removed_p = soup.p.extract()

# ۳. ساخت تگ جدید و افزودن به سند
new_badge = soup.new_tag("span", attrs={"class": "badge"})
new_badge.string = "جدید!"
soup.div.append(new_badge)

# ۴. تغییر نام تگ و ویژگی‌ها
soup.div.name = "section"
soup.section["id"] = "main-section"

print(soup.section)
# <section class="box" id="main-section"><span class="badge">جدید!</span></section>

۱۲ پروژه عملی جامع: اسکرپر حرفه‌ای با Requests و BS4

در کد زیر، یک الگوی استاندارد و آماده استفاده در محیط واقعی (Production-Ready) را مشاهده می‌کنید که شامل Session، هدر مرورگر، مدیریت خطاها، استخراج ایمن تگ‌ها و ذخیره خروجی در فایل CSV است:

python — full_scraper_project.py
import csv
from urllib.parse import urljoin
import requests
from bs4 import BeautifulSoup

BASE_URL = "https://books.toscrape.com/"
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Accept-Language": "fa-IR,fa;q=0.9,en-US;q=0.8,en;q=0.7"
}

def scrape_books(url: str) -> list[dict]:
    results = []
    with requests.Session() as session:
        session.headers.update(HEADERS)
        try:
            response = session.get(url, timeout=10)
            response.raise_for_status()
        except requests.RequestException as e:
            print(f"خطا در دریافت صفحه: {e}")
            return results

        # استفاده از response.content به جای response.text برای تشخیص دقیق‌تر انکودینگ توسط BS4
        soup = BeautifulSoup(response.content, "lxml")

        for card in soup.select("article.product_pod"):
            title_el = card.select_one("h3 a")
            price_el = card.select_one("p.price_color")
            stock_el = card.select_one("p.instock.availability")

            title = title_el.get("title", "بدون عنوان") if title_el else "نامشخص"
            rel_link = title_el.get("href", "") if title_el else ""
            full_link = urljoin(url, rel_link)
            price = price_el.get_text(strip=True) if price_el else "0"
            stock = stock_el.get_text(strip=True) if stock_el else "نامشخص"

            results.append({
                "title": title,
                "price": price,
                "availability": stock,
                "url": full_link
            })

    return results

if __name__ == "__main__":
    books_data = scrape_books(BASE_URL)
    if books_data:
        with open("books.csv", "w", newline="", encoding="utf-8-sig") as f:
            writer = csv.DictWriter(f, fieldnames=books_data[0].keys())
            writer.writeheader()
            writer.writerows(books_data)
        print(f"{len(books_data)} کتاب با موفقیت ذخیره شد.")

۱۳ جدول تقلب سریع (Cheat Sheet) و رفع خطاهای رایج

هدف روش سنتی (find / find_all) روش انتخابگر CSS (select / select_one)
یافتن تگ با ID soup.find(id="main") soup.select_one("#main")
یافتن تگ با کلاس soup.find_all("div", class_="card") soup.select("div.card")
یافتن لینک‌های دارای href soup.find_all("a", href=True) soup.select("a[href]")
فرزند مستقیم tag.find_all("li", recursive=False) tag.select(":scope > li")

۳ خطای بسیار رایج در کار با Beautiful Soup و راه‌حل آن‌ها:

۱. خطای AttributeError: 'NoneType' object has no attribute 'text'
این خطا زمانی رخ می‌دهد که متد find() یا select_one() تگ موردنظر را پیدا نکرده و None برگردانده است. همیشه قبل از فراخوانی .text، وجود تگ را با if tag: بررسی کنید.
۲. خالی برگشتن لیست هنگام اسکرپ کردن سایت‌های مدرن (React / Vue / Angular)
اگر تگ‌ها را در Inspect مرورگر می‌بینید اما در خروجی BS4 وجود ندارند، یعنی محتوا با جاوااسکریپت (CSR) لود می‌شود. در این حالت ابتدا تب Network مرورگر (بخش Fetch/XHR) را بررسی کنید تا مستقیماً از API JSON سایت داده بگیرید، یا از ابزارهایی مثل Playwright و Selenium استفاده کنید.
۳. ارسال response.content به جای response.text
بهتر است بایت‌های خام (response.content) را به BeautifulSoup بدهید تا موتور داخلی UnicodeDammit خودش بر اساس تگ <meta charset="..."> انکودینگ دقیق را تشخیص دهد.
