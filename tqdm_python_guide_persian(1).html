آموزش جامع ماژول tqdm در پایتون

کتابخانه tqdm ابزاری فوق‌العاده سریع و سبک برای اضافه کردن نوار پیشرفت (Progress Bar) حرفه‌ای به حلقه‌ها و پردازش‌های طولانی در پایتون است.

⚙️ شبیه‌ساز زنده (Interactive Playground)
bash - python script.py
برای شروع روی دکمه «اجرای شبیه‌سازی» کلیک کنید...
کد پایتون معادل:
for i in tqdm(range(100), desc="Processing Data"):

📚 مثال‌های کاربردی

۱. نصب و استفاده پایه

استفاده ساده در حلقه‌های for معمولی با پیچیدن حلقه دور tqdm یا استفاده از trange.

# نصب: pip install tqdm

from tqdm import tqdm, trange
import time

# روش اول
for i in tqdm(range(100), desc="حلقه ساده"):
    time.sleep(0.01)

# روش دوم (جایگزین range)
for i in trange(100, desc="با trange"):
    time.sleep(0.01)

۲. چاب عکس‌العمل با tqdm.write

برای چاپ پیام در ترمینال بدون خراب شدن نوار پیشرفت از write استفاده کنید.

from tqdm import tqdm
import time

for i in tqdm(range(10), desc="پردازش"):
    time.sleep(0.1)
    if i == 5:
        tqdm.write(f"پیام ویژه در گام {i}")

۳. به روزرسانی دستی (Manual Update)

مناسب برای دانلود فایل‌ها یا فرایندهایی که تعداد کل مشخصی دارند ولی حلقه نیستند.

from tqdm import tqdm
import time

with tqdm(total=1024, unit='B', unit_scale=True, desc="دانلود") as pbar:
    for _ in range(10):
        time.sleep(0.1)
        pbar.update(102.4) # افزایش دستی

۴. استفاده در Pandas

اضافه کردن نوار پیشرفت به متد apply روی DataFrame ها در پانداس.

import pandas as pd
from tqdm import tqdm

# فعال‌سازی روی پانداس
tqdm.pandas(desc="پردازش داده‌ها")

df = pd.DataFrame({"A": range(1000000)})
# استفاده از progress_apply به جای apply
df['B'] = df['A'].progress_apply(lambda x: x**2)

۵. استفاده در Jupyter Notebook

نمایش نوار پیشرفت گرافیکی و شکیل HTML مخصوص محیط ژوپیتر نوت‌بوک.

from tqdm.notebook import tqdm
import time

for i in tqdm(range(100), desc="Notebook Progress"):
    time.sleep(0.01)

۶. حلقه‌های تو در تو (Nested)

نمایش همزمان چندین نوار پیشرفت برای حلقه‌های داخلی و خارجی.

from tqdm import trange
import time

for i in trange(3, desc="اپوک"):
    for j in trange(50, desc="بچ‌ها", leave=False):
        time.sleep(0.01)

📋 جدول پارامترهای اصلی tqdm

پارامتر نوع داده مقدار پیش‌فرض توضیحات
iterable Iterable None شیء قابل پیمایش اصلی (مانند range یا لیست).
desc str None متن توضیحی قبل از نوار پیشرفت.
total int/float None تعداد کل گام‌ها (اگر طول iterable مشخص نباشد).
unit str 'it' واحد سنجش آیتم‌ها (مانند 'B' برای بایت یا 'file').
unit_scale bool/float False تبدیل مقادیر به پیشوندهای k, M, G (مثلاً ۱۰۰۰ بایت به 1k).
colour str None رنگ نوار پیشرفت (مثل 'green', 'blue', '#ff0000').
ncols int None عرض کل نوار در ترمینال بر حسب تعداد کاراکتر.
leave bool True حفظ نوار در ترمینال پس از پایان فرایند.
